
# SpendWise – Personal Finance Tracker

## Project Description

SpendWise is a simple, responsive personal finance tracking web application designed to help users manage their money more effectively.

Users can record income and expenses, monitor their total balance, organize transactions by category, and track their financial activities.

The application uses browser local storage to save transaction records, allowing users to retain their data after refreshing the page.

## Technologies Used

- HTML5 – Website structure.
- CSS3 – Styling and responsive design.
- JavaScript – Application functionality and calculations.
- Browser Local Storage – Saving transaction data.
- Git – Version control.
- GitHub – Source code hosting.
- Netlify – Website hosting and continuous deployment.

## Deployment Process Summary

The project was deployed using GitHub and Netlify.

1. Created and organized the SpendWise project files.
2. Developed the website using HTML, CSS and JavaScript.
3. Tested the application locally using a Python HTTP server.
4. Initialized a Git repository and committed the project files.
5. Created a public GitHub repository.
6. Pushed the project source code to GitHub.
7. Connected the GitHub repository to Netlify.
8. Configured Netlify to publish the project from the root directory.
9. Published the website using a Netlify subdomain.
10. Tested the live website to verify its functionality.
11. Updated the website footer and pushed the changes to GitHub.
12. Verified that Netlify automatically deployed the new changes.

## Challenges Encountered During Deployment

- Understanding how to connect a local project to a remote GitHub repository.
- Configuring the correct Netlify publishing directory.
- Ensuring that the website worked correctly after deployment.
- Testing the connection between GitHub and Netlify.
- Verifying that browser local storage preserved transaction data.

These challenges were addressed through testing, troubleshooting and following the deployment process step by step.
